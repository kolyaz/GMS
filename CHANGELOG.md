# GMS - ULA — релизы

Патч `0.0.1` поднимается на каждый запрос к агенту, который меняет продукт. Описание пишется сюда сверху.

## 0.1.3

- Вкладка «О программе»: проверка версии на GitHub Releases и кнопка «Обновить» (скачивает setup и запускает).
- Репозиторий релизов: `GITHUB_REPO` (по умолчанию `kolyaz/GMS`). Установщик в Release, не в истории git.

## 0.1.2

- Язык спрашивается только при первом запуске; WebView хранит `localStorage` в профиле.
- Очередь скачанных файлов на вкладке «Музыка» стоит над кнопкой «Скачать выбранные».

## 0.1.1

- Распознавание через Ollama: таймаут 15 минут, в ошибке — тело ответа Ollama.
- Перед распознаванием список движков обновляется; отсутствующая модель не уходит в запрос.

## 0.1.0

- Первая версия: чат, музыка с фото, локальная и облачные модели.
